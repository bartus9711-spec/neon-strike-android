# Character model attributions — TeamCS

This branch imports complete **digital 3D humanoid meshes** rather than
generating figures out of spheres and capsule primitives.

Character art source license: Creative Commons Attribution 4.0 International
(CC BY 4.0). Both character artists are credited below; the imported source
meshes were adapted for Godot, normalized to character height and repositioned
for use inside TeamCS. Neither creator endorses this game.

  "Military tactical suit (LowPolyGameReady)", CC BY 4.0. A modified copy
  (merged meshes, WebP textures) published as soldier_tac.glb in cktang88/3d-fps.
  Original: https://sketchfab.com/3d-models/military-tactical-suit-lowpolygameready-ef698ce36b1545a78ce592dd3db4c7ed
- Rigged humanoid (t_operator.glb): **BAMEN**,
  "FREE [Military Soldier] RIGGED", CC BY 4.0. A modified copy

  Original: https://sketchfab.com/3d-models/free-military-soldier-rigged-e9c56308a67d4a3db62e914fafa4d198

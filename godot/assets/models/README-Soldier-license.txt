TeamCS animated humanoid character asset
---------------------------------------
Soldier.glb is downloaded during the Godot CI import step from the Three.js example assets:
https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Soldier.glb

Upstream code is open-source under the MIT License:
https://github.com/mrdoob/three.js/blob/dev/LICENSE

Character format: GLB (skinned mesh)
Animations: Idle, Walk, Run, TPose
Downloaded in the GitHub Actions build; not written into the repository.

The other fallback game avatar, RobotExpressive.glb, comes from
Tomás Laulhé (Quaternius), explicitly CC0-1.0 in upstream README:
https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive

Use only assets with clear redistribution rights. Existing license notices
must be retained alongside asset sources as applicable.
